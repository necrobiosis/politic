# 红墙图鉴 · 规划文档

> 一个用「卡牌游戏 + 公司架构图」的戏谑方式，帮人看懂中国政治版图的非官方娱乐科普站。
> 数据截至 2026-10-31（二十届五中全会刚闭幕）。

---

## 1. 要解决什么问题

普通人看中国政治新闻，最常见的三个困惑：

| 困惑 | 网站给出的答案 |
|---|---|
| 这个人是谁？以前在哪、后来去了哪？ | **人物卡**：正面是头像+数值，背面是履历时间线、迁徙路线、派系、羁绊 |
| 这个部门是干嘛的？谁管谁？ | **公司架构图**：把党政军机构翻译成「中国有限公司」的部门，一键切换「正经/戏说」 |
| 最近谁上谁下？派系格局怎样？ | **版本更新公告**（人事变动 = 游戏补丁）+ **派系公会**页 |

设计原则：**一目了然 > 信息量**。首页 10 秒内看懂「谁在顶层」，点任何人 1 次就能看到他的来龙去脉。

## 2. 形式选择：为什么不以地图为主

- 地图的问题（同意你的判断）：真正重要的只有北京、上海、浙江、福建、广东等少数几个点，大片区域是空的，信息密度低。
- **主形式 1：公司架构图**——天然是自上而下的层级，最适合回答「谁管谁」。
- **主形式 2：卡牌**——最适合承载「一个人」的全部信息，并且自带游戏化（抽卡、收集、稀有度），让人愿意多点几张。
- **辅助形式：方块地图（Tile Map）**——不用真实地理形状，31 个省级单位等大方块，用来画「迁徙路线」和「升迁跳板省」热力，这是地图唯一真正有价值的用途。

## 3. 信息架构（导航）

```
首页（版图速读 + 头条补丁 + 入口）
├── 🏢 架构图   中国有限公司组织架构（正经/戏说双模式）
├── 🃏 卡牌图鉴  全部人物卡、筛选、搜索、抽卡、收集进度
├── ⚔️ 派系公会  之江新军/福建帮/陕西帮/清华帮/团派/航天系…
├── 🗺️ 迁徙地图  方块地图：各省现任书记 + 任意人物的调动路线
├── 🏛️ 部门图鉴  这个部门是干嘛的？正经职能 vs 戏说解读
├── 📜 更新公告  人事变动 = 游戏补丁说明（上新/下架/调岗/平衡性调整）
└── ℹ️ 关于     免责声明、数值算法、黑话词典、数据来源
```

全局：顶部搜索框（姓名/拼音/外号/职务/省份/派系/部门），任何人名点击都打开人物详情。

## 4. 卡牌系统设计

### 4.1 稀有度（= 职级）

| 稀有度 | 对应 | 说明 |
|---|---|---|
| **UR** | 总书记 | 全服唯一 |
| **SSR** | 政治局常委 | 7 人 |
| **SR** | 政治局委员 / 国家副主席 | 「董事会成员」 |
| **R** | 国务委员、关键部长、省委书记 | 「分公司总经理」 |
| **传说** | 已退休/已故的前任大佬 | 「怀旧服」 |
| **已下架** | 落马、开除党籍、审查中 | 灰色卡面 + 「已下架」印章 |

### 4.2 卡面数值（纯属娱乐，算法公开）

- **⚔️ 攻击力（权力）**：职务排名 + 分管领域实权（组织、纪检、宣传、军队、政法、财经、中办）。
- **🛡️ 防御力（稳固度）**：与「核心」的共事渊源 + 年龄余量 + 所在派系当前版本强弱。落马卡防御力为 0（已破防）。
- **🧭 迁徙值**：自动计算——履历中走过多少个省级单位/中央/海外。
- **⏳ 七上八下倒计时**：自动计算 2027 年二十一大时的年龄，≥68 岁标「按惯例到点」。

### 4.3 卡背内容

一句话简介 → 履历时间线（迁徙路线）→ 派系标签（注明「坊间说法」）→ 技能（戏谑化的政绩/名场面）→ 羁绊（与其他卡的关系，可点击跳转）→ 梗与外号。

### 4.4 游戏化

- **抽卡**：单抽/十连，按稀有度加权；抽到的卡进入「我的图鉴」（存本地浏览器）。
- **收集进度**：已收集 X / 全部，激励把所有人看一遍——这本身就是学习。

### 4.5 头像

使用真实照片：全部取自 Wikimedia Commons 的自由授权图片（CC BY / CC BY-SA / 公有领域），下载到 `img/people/` 本地托管，
人物页与「关于」页逐张标注作者、授权与原图链接。落马卡灰度、怀旧卡褐色调。暂无自由授权照片的人物显示姓氏字牌。

## 5. 架构图设计（中国有限公司）

```
                   董事长 习近平（总书记·国家主席·军委主席）
                                │
  ┌──────────── 董事会常务委员会（政治局常委 7 人）────────────┐
  李强        赵乐际        王沪宁       蔡奇         丁薛祥       李希
  运营中心    股东大会      顾问委员会   总裁办+秘书处  常务副总     内审合规部
  (国务院)    (全国人大)    (全国政协)   (书记处/中办)  (国务院)     (中纪委)
     │           │             │            │                        │
  副总理/部委  李鸿忠…      石泰峰…      组织/宣传/统战/政法…        …
  
  直属：安保部（中央军委）——编制 7 人，现存 2 人
  分公司：北京/上海/天津/重庆/广东（政治局委员坐镇）+ 其余各省
```

- **正经模式**：显示官方全称。**戏说模式**：显示公司化/网络梗名称。默认戏说，一键切换——同时满足「好玩」和「能学到真东西」。

## 6. 数据模型

所有数据放在 `js/data/*.js`，与渲染代码分离，方便后续更新：

| 文件 | 内容 |
|---|---|
| `people.js` | 人物：职务、出生年月、履历（时间/地点代码/机构/职务）、派系、数值、技能、羁绊、梗、状态 |
| `factions.js` | 派系公会：名称、来源、代表人物、当前版本状态 |
| `departments.js` | 部门：官方名、戏称、职能、戏说解读、一把手、所属层级 |
| `changelog.js` | 人事变动补丁：日期、类型（上新/下架/调岗/版本更新）、涉及人物 |
| `places.js` | 省级单位、方块地图坐标、现任书记 |
| `glossary.js` | 黑话词典：七上八下、双开、留置、递补、追认… |

人物关系（羁绊）只需单向录入，程序自动生成反向关系。迁徙值、年龄、七上八下等全部自动计算。

`scripts/validate.js` 校验数据完整性（引用的 id 是否存在、地点代码是否合法等）。

## 7. 技术方案

- **纯静态站，零依赖、零构建**：HTML + CSS + 原生 JS，双击 `index.html` 即可打开，可直接部署到 GitHub Pages / Vercel / Netlify。
- Hash 路由（`#/cards`、`#/p/liqiang`），人物详情可直接分享链接。
- 响应式（手机可用）+ 深色模式。
- 收集进度用 `localStorage`，失败时静默降级。

## 8. 内容原则（戏谑但不造谣）

1. **事实部分**（职务、履历、任免日期）只写官方公开信息，落马人员只写官方通报的定性与时间。
2. **派系标签**明确标注为「坊间/海外观察者常用说法，非官方分类」。
3. **戏谑部分**只调侃公开的名场面、官方话术与制度本身，不编造私德八卦。
4. 每页底部注明数据截止日期；人事变动频繁，以官方发布为准。
