# 红墙图鉴 · 中国政治版图戏说版

用**卡牌游戏 + 公司架构图**的方式，戏谑又不失准确地看懂中国政治版图：

- **谁在顶层？** —— 「中国有限公司」组织架构图，董事长 → 董事会常委 → 各事业部 → 分公司
- **这个人从哪来、去了哪？** —— 人物卡正面是数值，背面是履历与迁徙路线
- **他和谁是一伙？** —— 之江新军、福建帮、陕西帮、清华帮、团派……派系公会 + 羁绊关系图
- **这个部门干嘛的？** —— 每个部门都有「正经职能」和「戏说解读」两种读法
- **最近谁上谁下？** —— 人事变动写成游戏「版本更新公告」

> 数据截至 **2026-10-31**（二十届五中全会刚闭幕）。非官方娱乐科普，人事信息以官方发布为准。

## 功能一览

| 页面 | 内容 |
|---|---|
| 首页 | 版图速读（现任政治局人数、军委在岗人数、2027「到点」常委）、最新补丁、升迁跳板省 Top 5 |
| 🏢 架构图 | 自上而下的组织架构，一键切换「正经 / 戏说」命名 |
| 🃏 卡牌图鉴 | 80 张人物卡；稀有度（UR / SSR / SR / R / 传说 / 已下架）；筛选、排序；**抽卡 + 收集进度** |
| ⚔️ 派系 | 14 个派系公会的来源、版本强度、在场/离场成员；以任意人物为中心的羁绊关系图 |
| 🗺️ 迁徙地图 | 方块地图：各省现任书记、升迁跳板热度、任意人物的调动路线 |
| 🏛️ 部门 | 29 个部门的职能与戏说解读 |
| 📜 更新公告 | 2022 年二十大以来的人事变动「补丁说明」 |
| 👤 人物档案 | 数值、七上八下倒计时、履历时间线、迁徙路线、技能、梗、羁绊、相关补丁 |

卡面数值：⚔️ 攻击力（权力）、🛡️ 防御力（稳固度）为编辑部主观估算；🧭 迁徙值、⏳ 七上八下倒计时由履历和出生年月**自动计算**。

## 运行

纯静态网站，零依赖、零构建：

```bash
# 直接双击 index.html 即可；或起一个本地服务器
python3 -m http.server 8000
# 打开 http://localhost:8000
```

部署：把仓库根目录发布到 GitHub Pages / Vercel / Netlify 任一静态托管即可。

## 更新数据

所有数据在 `js/data/`，与页面代码分离：

| 文件 | 内容 |
|---|---|
| `people.js` | 人物：职务、履历 `[起, 止, 地点代码, 职务]`、派系、数值、技能、羁绊、梗 |
| `factions.js` | 派系 |
| `departments.js` | 部门（`under` 决定在架构图中挂在哪位常委下） |
| `changelog.js` | 更新公告 |
| `places.js` | 省级单位、方块地图坐标、现任书记 |
| `glossary.js` | 黑话词典 |

改完运行校验：

```bash
node scripts/validate.js
```

羁绊关系只需单向录入，程序会自动生成反向关系。设计思路与迭代计划见 [docs/PLAN.md](docs/PLAN.md)。

## 内容原则

1. 职务、任免时间、官方处分只写公开信息，落马人员只写官方通报的定性与时间。
2. 派系标签是坊间/海外观察者的常用说法，**非官方分类**，页面上均有标注。
3. 戏谑部分只调侃公开的名场面、官方话术和制度本身，不编造私德八卦。
4. 头像为程序生成的风格化剪影，不使用真人照片（数据里预留了 `photo` 字段）。
